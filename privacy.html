개인정보처리방침 — ERICJUN Upload

시행일: 2026년 10월 31일

1. 어떤 프로그램인가요

ERICJUN Upload는 에릭준(ERICJUN)이 본인 PC에서만 사용하는 개인용 프로그램으로, 에릭준 본인의 유튜브 채널에 영상을 업로드·예약 공개하는 데 쓰여요. 일반 사용자에게 제공되는 서비스가 아니에요.

2. 사용하는 구글 데이터

Google 로그인으로 허용된 범위 안에서 YouTube Data API를 통해 다음 작업만 해요.

  • 본인 채널 이름·ID 확인
  • 영상 업로드와 예약 공개 설정, 썸네일 등록, 재생목록 추가
  • 본인 영상에 댓글 작성, 업로드한 영상의 공개 상태 확인

3. 저장과 공유

로그인 토큰은 에릭준 본인 PC에만 저장되고, 외부 서버로 보내거나 다른 사람·회사와 공유·판매하지 않아요. 광고나 분석 목적으로 쓰지 않아요.

Google API에서 받은 정보는 Google API Services User Data Policy(Limited Use 요구사항 포함)를 따라 위 기능에만 사용해요.

4. 접근 권한 취소

언제든지 Google 계정 → 보안 → 서드파티 액세스에서 이 앱의 접근 권한을 삭제할 수 있어요. 삭제하면 PC에 저장된 토큰도 더 이상 쓸 수 없어요.
